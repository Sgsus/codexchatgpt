# Contexto do projeto

Organizar o trabalho no repositório `Sgsus/codexchatgpt`, com documentação clara para humanos e assistentes.

- Conteúdo atual: documentação, orientações de trabalho e modelos de tarefa/revisão.

## Decisões
- Manter a estrutura pequena até existir um objetivo de aplicação.
- Não inventar comandos ou afirmar integrações que não foram configuradas.
- Não armazenar dados privados neste repositório público.
- A documentação deste repositório não instala nem repara a extensão oficial do ChatGPT.
